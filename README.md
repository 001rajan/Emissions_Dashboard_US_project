# US_Emission_Dasshboard
This dashboard analyzes greenhouse gas emissions across U.S. counties using Databricks SQL. Interactive visualizations highlight emission distribution, population impact, geographic patterns, and top-emitting regions, enabling data-driven environmental insights.
🌎 US Greenhouse Gas Emissions Dashboard
Project Overview

This project presents an interactive dashboard developed in Databricks SQL to analyze greenhouse gas (GHG) emissions across counties in the United States. The dashboard combines geospatial visualization, emission distribution analysis, and population-based metrics to identify environmental trends and high-impact regions.

Dashboard Features
Interactive emission map visualization
Population vs. emission scatter analysis
Emission percentage distribution by state
Top emitting counties ranking
KPI metrics for population and emissions
Dynamic filtering capabilities
